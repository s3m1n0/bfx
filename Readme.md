# bfx

## installation

### Build from source

Requirements:

- C++20 compatible compiler
- CMake 3.28 or later
- Make

Clone the repository and build the project:

1. `git clone https://github.com/s3m1n0/bfx.git`
2. `cd bfx`
3. `mkdir build`
4. `cd build`
5. `cmake ..`
6. `make`

## usage 

just point bfx to the brainfuck source code and enjoy :)                          

```bash
./bfx file_to_parse.bf
```
