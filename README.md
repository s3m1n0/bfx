# bfx

## installation

### Build from source

Requirements:

- C++20 compatible compiler
- CMake 3.28 or later
- Make

Clone the repository and build the project:


1. cmake -S . -B build
2. cmake --build build


## usage 

just point bfx to the brainfuck source code and enjoy :)                          

```bash
./bfx file_to_parse.bf
```
